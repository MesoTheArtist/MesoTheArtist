**OJA247** — A digital marketplace built with React, Node.js, Express, and MongoDB, giving small Nigerian businesses an online storefront: vendor onboarding, payments, disputes, and customer accounts.

**Core features:** Vendor onboarding & KYC, product management, cart & checkout, Paystack/Flutterwave integration, customer accounts, order tracking, dispute system, admin dashboard.

```bash
# Quick start
git clone https://github.com/LaBoss999/OJA247.git
cd OJA247
npm install
cd client && npm install && cd ..
# Add .env -> MONGO_URI, JWT_SECRET, PAYSTACK_KEY
npm run dev
